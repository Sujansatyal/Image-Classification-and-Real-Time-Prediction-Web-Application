# Image Classification and Real-Time Prediction

## Project Overview

This project classifies images from the CIFAR-10 dataset using Deep Learning and provides real-time predictions through a Streamlit web application. The project includes a Custom CNN, Hyperparameter Tuning using Keras Tuner, and Transfer Learning with MobileNetV3.

## Technologies Used

- Python
- TensorFlow / Keras
- Keras Tuner
- NumPy
- Matplotlib
- Scikit-Learn
- Streamlit
- Pillow

## Features

- Image Classification using CIFAR-10
- Custom CNN Model
- Hyperparameter Tuning
- MobileNetV3 Transfer Learning
- Real-Time Image Prediction
- Confusion Matrix and Performance Evaluation

## How to Run

### Clone the Repository

```bash
git clone <repository_link>
cd Image_Classification
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Streamlit Application

```bash
streamlit run streamlit_app.py
```

### Open Browser

```
http://localhost:8501
```
